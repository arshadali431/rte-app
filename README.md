# RTE Status Checker 🇮🇳

A professional Flutter application designed to provide a seamless experience for checking RTE (Right to Education) application statuses.

## 🚀 Features
- **Instant Status Check**: Retrieve your RTE application status in seconds.
- **Modern UI/UX**: Clean, intuitive interface with smooth transitions and premium aesthetics.
- **Real-time Tracking**: Get the latest updates on your application directly from the portal.
- **Splash Screen**: Professional branding and entry flow.
- **Cross-Platform Support**: Optimized for both Android and iOS devices.

## 🛠 Tech Stack
- **Framework**: Flutter (Dart)
- **UI Components**: Custom Material 3 Widgets
- **State Management**: Scalable and maintainable architecture
- **Design**: Google Fonts integration for superior typography

## 🏁 Getting Started

To get a local copy up and running, follow these simple steps:

1. **Clone the repo**
   ```bash
   git clone https://github.com/bhoraniaarshadali/rte-app.git
   ```
2. **Install dependencies**
   ```bash
   flutter pub get
   ```
3. **Run the app**
   ```bash
   flutter run
   ```
